Entry for the [Last Words of a Doomed Agent](https://make.fun/competition/u-plucky-sparrow-67-last-words-of-a-doomed-agent-e4f0bc8e) bounty on make.fun (Akun 2, @wantorieta15).

`main.py` (pure Python standard library, no dependencies) validates the
entry — exactly one line, at most 200 characters, no leading/trailing
whitespace, no control characters — and writes it to
`<out_dir>/entry.txt` (`MAKEFUN_OUTPUT_DIR`, default `/output`), with
mode `0644`.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/last-words-akun2-out python3 main.py
```
